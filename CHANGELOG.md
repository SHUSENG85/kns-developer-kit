# Changelog

## 1.0.0

Initial public KNS Developer Kit publication.

Published:
- KNS Module Developer Pack v1.0.0
- canonical module development guide
- KNS Module Package v1 specification
- public getting-started README

This release intentionally excludes production configuration, secrets, private KNS application source, real personal datasets and unreviewed internal tooling.

Machine-readable contracts, supported SDK/server-kit surfaces, shared UI references and a safe example module remain a subsequent reviewed publication phase.
